# ClearRate — Credit Cards & Bank Accounts Comparison (USA)

> Independent comparison of credit cards, bank accounts, savings & insurance in the USA.

**ClearRate** is a free, independent financial comparison platform helping users find the **best credit cards and bank accounts** with side-by-side tools, honest reviews, and up-to-date rates.

## ✨ Features

- 💳 **Credit card comparison** — rewards, cashback, travel, bad credit
- 🏦 **Bank account finder** — checking, savings, high-yield accounts
- 🎓 **Student finance hub** — cards & accounts built for students
- 📊 **Side-by-side comparison tool** — see all the numbers at once
- 🔒 **Security-first** — read our privacy policy before you apply
- 📱 **Responsive, clean UI** — no clutter, no dark patterns

## 🛠️ Built With

- HTML5 + CSS3 + JavaScript
- SEO-optimized static pages
